# GraphRAG Papers

Учебный GraphRAG для поиска и ответов по английским аннотациям научных статей arXiv. Стек: Python 3.12+, Neo4j, Sentence Transformers, Ollama и FastAPI.

## Как работает

1. Статьи и извлечённые LLM тройки загружаются в Neo4j: `Paper`, `Entity`, `MENTIONS`, `R`.
2. `all-MiniLM-L6-v2` строит 384-мерные embeddings названий сущностей и статей.
3. Поиск сочетает имена методов в заголовках с векторным поиском и выбирает до трёх статей.
4. К аннотациям добавляются извлечённые графовые факты с provenance `source_ids`.
5. `qwen2.5:7b-instruct-q4_K_M` через Ollama отвечает по контексту на английском со ссылками на источники.

Это прототип, не production-сервис. Факты графа могут быть ошибочны. Последняя проверка — пять development-вопросов с одинаковым retrieval в обоих вариантах (с графом / без графа); она **не доказывает превосходство GraphRAG**. Разметка, код и учебные материалы создавались с помощью ИИ.

## Установка и настройки

Нужны [uv](https://docs.astral.sh/uv/), Neo4j с поддержкой векторных индексов и Ollama. Выполняй команды из корня проекта:

```bash
uv sync --locked
cp .env.example .env
# Укажи свой пароль Neo4j в .env, затем экспортируй его:
set -a
. ./.env
set +a
ollama pull qwen2.5:7b-instruct-q4_K_M
```

`.env` не загружается автоматически: экспортируй переменные в каждой новой shell-сессии. Neo4j ожидается на `bolt://localhost:7687` (пользователь `neo4j`), Ollama — на `http://localhost:11434`. Без `NEO4J_PASSWORD` передаётся пустой пароль; при обычной включённой аутентификации подключение не пройдёт. Первый запуск Sentence Transformers скачивает модель.

## Подготовка новой локальной БД

Следующие команды **изменяют БД**. Запускай только на отдельной учебной базе; сначала сделай backup, если в ней уже есть данные.

```bash
uv run python scripts/load_graph.py
uv run python scripts/add_abstracts.py
uv run python scripts/embeddings.py
uv run python scripts/qa.py
```

Последняя команда создаёт индекс `paper_vec`, если его нет, и генерирует демонстрационный ответ. Дождись, пока векторные индексы станут `ONLINE`, прежде чем отправлять запросы. Для воспроизведения сохранённого снимка могут требоваться дополнительные шаги нормализации/миграций — см. [разбор](review/PROJECT_REVIEW_RU.md); базовые команды выше не гарантируют идентичные числа.

`fetch_papers.py` и `extract_triplets.py` нужны только для нового сбора/извлечения; они могут перезаписать или дополнить файлы в `data/`. `rebuild_relations.py` и `merge_actgcg.py` — отдельные операции изменения графа, не автоматические шаги запуска.

## API

После подготовки БД и экспорта пароля:

```bash
uv run uvicorn app:app --app-dir scripts --host 127.0.0.1 --port 8000
curl http://127.0.0.1:8000/health
curl -X POST http://127.0.0.1:8000/ask \
  -H 'Content-Type: application/json' \
  -d '{"question":"Which methods improve retrieval-augmented generation?"}'
```

`GET /health` — проверка живости процесса, не полноценная проверка Neo4j/Ollama. UI и авторизации API нет; не открывай его в интернет.

## Проверки без БД и генерации

```bash
uv run python -B -m unittest discover -s tests -v
uv run python -B review/tools/verify_package.py
```

36 unit-тестов; верификатор проверяет хеши, сохранённые результаты и экспорт Anki. Интеграционные тесты с живыми сервисами и ручная оценка ответов ими не заменяются. Команда `graphrag-papers` пока является placeholder, а не запуском pipeline.

## Безопасность и сторонние материалы

Пароль задаётся только через `NEO4J_PASSWORD`; `.env`, логи, окружение и новые backups исключены из Git. Старый локальный пароль не публикуется; сменить его в самой БД нужно отдельно.

Данные статей происходят из arXiv; права на тексты остаются у соответствующих правообладателей. Локальная копия стороннего skill в `.agents/` сохраняет upstream attribution и MIT license; она не требуется для работы GraphRAG.
